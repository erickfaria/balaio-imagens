# Balaio Científico — imagens / images

Espelho público exclusivo das imagens de posts aprovados do Balaio Científico.

## Organização

```text
<identificador-do-post>/
  <hash-da-imagem>.webp
```

Os originais ficam junto do Markdown na pasta de cada post, no repositório privado de conteúdo. Este espelho recebe somente imagens efetivamente usadas em textos aprovados; não recebe Markdown, rascunhos, CSVs ou credenciais. Imagens de agendamentos ficam públicas quando são enviadas, antes da publicação do texto.

## Controle de alterações

- Proprietário: **@erickfaria**, com controle total.
- Não há colaboradores externos com escrita.
- A única automação autorizada usa uma chave exclusiva para enviar imagens. Ela não pode forçar o histórico nem excluir branches.
- Branches protegidas por regras de atualização, exclusão e histórico. Pull requests externos não são incorporados automaticamente.
- GitHub Actions está desativado neste espelho. O processamento ocorre no repositório privado de conteúdo.

Public access allows reading and copying the images; it does not grant write access to this repository. Only the owner and the explicitly authorized image publisher may update it. Original Markdown and drafts remain private. Images are addressed by post identity and content hash, with revision-pinned URLs used in published articles.

Não exclua imagens referenciadas por posts publicados. / Do not remove images used by published posts.
